# fortress-measure

FORTRESS doctrine: build what can't be taken. Measurement is where that doctrine gets tested against results — not every number that goes up means ground was actually held.

## 1. Few numbers, honestly

Track a small number of metrics, and be honest about what each one actually shows. A long dashboard doesn't make the picture clearer — it makes it easier to find a number that looks good and report that one instead of the ones that matter. Fewer numbers, checked without flinching, beat a wall of charts nobody reads critically.

## 2. The question: durable, or just noise?

For every metric under consideration, ask: **did this build something durable, or just make noise?**

A motte number — subscribers, an owned email list's size, direct customer relationships, domain traffic that doesn't depend on one platform's algorithm — measures something that stays even if a platform disappears tomorrow. A bailey number — impressions, likes, shares, follower count on a single platform — measures attention that platform is currently lending and can reclaim without notice.

A motte number beats a bailey number every time it's available. Where only a bailey number exists, use it, but label it for what it is: a proxy for attention rented this week, not a claim on anything owned. See `fortress-motte` for the full asset-level version of this same test.

| Motte number | Bailey number |
|---|---|
| Email list size | Follower count |
| Direct signups from owned channels | Post impressions |
| Repeat visits to the owned domain | Likes, shares, reactions |
| Customers reachable without a platform's permission | Engagement rate |

## 3. Kill what produced nothing

If a channel or a campaign has been running long enough to have produced a result and the result is nothing, stop it. Don't keep it running while writing an explanation for why it hasn't worked yet — a channel earns continued investment by producing something, not by having a plausible story for why it might eventually. The explanation is not the same as the result, and time spent defending a dead channel is time not spent on one that's working.

This is the same discipline `fortress-bailey`'s exclusion register applies to channels that were never tried: record why, in the same place, so the decision doesn't get silently re-litigated next session.

## 4. Vanity metrics are a way of losing slowly

A rising bailey number feels like progress. It can be exactly that — or it can be a platform's attention, on loan, climbing toward a peak from which it will eventually be reclaimed, with the adopter's actual position — the motte — unchanged the entire time. The danger isn't that vanity metrics are fake; it's that they're real and still don't compound into anything ownable. Watching one climb while the motte stays flat is losing ground slowly enough that it doesn't feel like losing until the platform changes terms and the number resets to zero.

Check the motte number alongside every bailey number that's being celebrated. If the bailey number moved and the motte number didn't, the campaign produced attention, not an asset.

## 5. No decision, no metric

A metric with no decision attached to it should not be tracked. Before adding any number to what gets reviewed, name the decision it would change: what gets kept running, what gets killed, what gets tried next, depending on which way the number moves. If no answer comes to mind, the metric is decoration — it costs attention to collect and report, and returns nothing, because nothing downstream of it ever actually changes based on its value.
